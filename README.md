# Landing Page - Snap
## 🧩 Sobre o Projeto

O Workit foi desenvolvido com o objetivo de aprimorar e validar os conhecimentos em HTML, CSS e design responsivo.
Durante o desenvolvimento, foram aplicadas boas práticas de estruturação semântica, estilização moderna e adaptação do layout para diferentes tamanhos de tela, garantindo uma experiência consistente em dispositivos móveis e desktops.

### Funcionalidades principais:
- **Design Responsivo**: A página foi construída para se adaptar a diferentes tamanhos de tela, garantindo uma boa experiência em dispositivos móveis, tablets e desktops.
- **Prototipação**: O design da página foi prototipado e validado no **Figma** antes da implementação.
- **Tecnologias Usadas**: **HTML**, **CSS**, **JavaScript**.
